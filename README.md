# m2send

受信者が作った使い捨ての公開鍵で、テキストやファイルを暗号化して渡すツールです。ブラウザは最初に静的なページを読み込み、以降の操作は端末内で行います。

## ローカルで開く

リポジトリのルートで実行し、[http://127.0.0.1:8000/](http://127.0.0.1:8000/) を開きます。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

GitHub Pages に公開する際は、公開元にリポジトリのルートを指定し、HTTPS を有効にします。追加のビルドは不要です。

## 使い方

1. 受信者は「受け取る」で鍵を作り、送信用リンクを相手に渡します。別のタブや後日の復号に備える場合は、秘密鍵を手動で保存します。
2. 送信者はリンクを開き、テキストやファイルを暗号化して受信者に返します。公開証明書（PEM）の貼り付けにも対応します。
3. 受信者は同じタブ、または保存した秘密鍵で復号します。やり取りを終えたら「鍵を破棄」を押し、保存していた秘密鍵も端末で削除します。

送信用リンクには公開証明書だけが入ります。本人から届いたと確認できるリンクを使ってください。指紋は必要な場合に画面で照合できます。保存される秘密鍵ファイルは平文の PKCS#8 PEM です。

テキストは最大 1 MiB、ファイルは最大 16 MiB です。ファイル名は暗号文に含めないため、復号すると `m2send-decrypted` という名前になります。

## OpenSSL とやり取りする

AI エージェント用の [m2send スキル](./skills/m2send/SKILL.md) に、鍵の生成、リンクの読み書き、暗号化、復号の手順があります。

共通形式は単一受信者の CMS AuthEnvelopedData です。鍵の暗号化は RSA-2048 OAEP（SHA-256、MGF1-SHA-256）、本文は AES-256-GCM（12 バイトの nonce、16 バイトのタグ）を使います。暗号文は貼り付け用の PEM またはファイル用の DER で渡せます。
